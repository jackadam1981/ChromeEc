# Implementation

The top level file is `rts54.lua`. All other required files in
included from there and are typically called `rts54-*.inc`.

The rts54 dissector installs itself under `DLT_USER0` (147)
[ref](https://www.tcpdump.org/linktypes.html). This is used
to dissect PCAP files generated by unit tests.

The rts54 dissector also installs itself on UDP port 2012. The choice of
port number is largely arbitrary as long as the generator and wireshark
agree on the port number. This is used for the live capture case.

For live capture, we simply have `ectool` poll the EC for messages
(`CONFIG_USBC_PDC_TRACE_MSG` must be enabled) and forward these to a
specified IP address on UDP port 2012.

Note: Ideally, one would use the wireshark
[extcap](https://www.wireshark.org/docs/man-pages/extcap.html)
interface, however since wireshark isn't available where EC access is
possible, this may not be feasible.
